# Metadata Visualizations Script

### Purpose
This script is the visual component of the Exploratory Data Analysis (EDA) phase for the PREPARE Challenge dataset. It takes the aggregated data generated by the metadata summary script and creates high-quality, publication-ready charts. These visualizations help the research team easily understand the distribution of patient demographics (Age, Gender), clinical diagnoses, and languages before running the core ASR and NLP pipelines.

### Inputs
* **Required Files:** The aggregated metadata summary file.
* **File Format:** `.csv` file (e.g., `metadata_summary.csv`).
* **Parameters:** The script expects the input CSV to contain `Category`, `Value`, and `Count` columns to accurately map the distributions.

### Outputs
* **Generated Outputs:** A collection of data visualization charts.
* **File Format:** `.png` image files.
* **Structure:** - Individual bar charts for primary categories (e.g., `Gender_distribution.png`, `Diagnosis_distribution.png`, `Language_distribution.png`, `Split_distribution.png`).
  - Specialized age charts: A grouped pie chart (`Age_grouped_pie.png`) and an exact age bar chart highlighting the maximum and minimum frequencies (`Age_exact_distribution.png`).
  - All outputs are systematically saved to the designated `OUTPUT_DIR`.

### Configuration
The script utilizes hardcoded constant variables at the top for easy path management:
* `INPUT_FILE`: The path to the summary dataset generated in the previous step (Default: `.../metadata_summary.csv`).
* `OUTPUT_DIR`: The destination folder where all generated `.png` charts will be saved. The script automatically creates this directory if it does not already exist.

### Dependencies
The following Python libraries are required to run this script:
* `pandas` (for reading and manipulating the CSV data)
* `matplotlib.pyplot` (for base plotting mechanics)
* `seaborn` (for advanced, aesthetically pleasing statistical graphics)
* Built-in Python modules: `os`
