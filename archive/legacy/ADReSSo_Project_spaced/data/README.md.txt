DATA DIRECTORY

This folder holds all the audio and text files for the pipeline. Each script reads data from one folder and saves its results to the next folder in the chain.

FOLDER STRUCTURE

train_audios/
What it is: Raw, original audio files (.wav).
Used in: Input for Step 1.

processed_audios/
What it is: Cleaned audio files ready for the AI model.
Used in: Output from Step 1 / Input for Step 2.

transcripts/
What it is: AI-generated text files (.json) created by the Whisper model.
Used in: Output from Step 2 / Input for Step 3.

gold_transcripts/
What it is: The correct, human-written reference texts (.txt).
Used in: Input for Step 3.

alignment_reports/
What it is: CSV files showing how the AI text matches the correct text.
Used in: Output from Step 3 / Input for Step 4.

verticalized_data/
What it is: CSV files where words are listed top-to-bottom with error types (MATCH, DELETION, INSERTION, SUBSTITUTION).
Used in: Output from Step 4 / Input for Step 5.

FINAL OUTPUT

Master_Report_Final.xlsx
What it is: The final Excel file generated by Step 5. It contains the total Word Error Rate (WER), NLP error categories, and clinical analysis.
